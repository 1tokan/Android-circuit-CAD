# Pocket EDA

Androidで動く電子回路・PCB設計CAD（PWA）。最終目標は、LCSCの部品で回路図とPCBを設計し、JLCPCBに発注できるGerber・BOM・CPLを生成することです。

**現在: 第3段階（部品ライブラリ・ネットリスト）まで完了**。PCB・ERC/DRC・製造データ出力はまだ実装しておらず、画面上でも「未実装」と表示します。

## 第3段階: 部品ライブラリ・LCSC部品・ネットリスト

**LCSC公式APIは使いません**。APIは存在しますが、申請制で secret による署名が必要なため、サーバーを持たないPWAには安全に組み込めません（docs/ROADMAP.md）。代わりに次の方式で部品を扱います。外部サービスが使えなくても内蔵部品で設計を続けられます。

| 方式 | 内容 |
|---|---|
| CSV取込 | JLCPCB部品ライブラリのCSV、CDFER/jlcpcb-parts-database のCSV、jlcparts形式、日本語見出しの自作CSV。列名の表記ゆれ（`LCSC Part` / `JLCPCB Part #` / `lcsc` など）を吸収し、カテゴリ・説明からシンボル種別、パッケージからフットプリントを推定 |
| JSON取込・書出 | 部品ライブラリを `pocket-eda-library` 形式でやり取り |
| 手動登録・編集 | 名称・種別・値・メーカー・型番・LCSC品番・パッケージ・フットプリント（内蔵 or 独自JSON）・ピン→パッド対応・データシート・JLCPCB区分・価格・在庫・電気的仕様 |
| LCSC/JLCPCBへのリンク | 部品詳細から商品ページを開いて価格・在庫・品番を確認 |
| **オンライン検索（jlcsearch）** | 申請不要。部品画面の「オンライン検索」で、型番・LCSC品番・値から JLCPCB 部品を検索し、LCSC品番・価格・在庫・Basic/Extended区分を取得して端末のライブラリに保存 |

### オンライン検索（jlcsearch）について
- [jlcsearch](https://docs.tscircuit.com/web-apis/jlcsearch-api) は tscircuit が公開しているコミュニティAPI（認証不要）で、KiCad の JLCPCB プラグインと同じく yaqwsx/jlcparts の部品データを元にしています。**LCSC公式ではありません**
- 送るのは検索語だけ。呼び出しは0.7秒以上空け、同じ検索は10分キャッシュ
- 保存済みの部品を検索結果から保存し直すと、利用者が決めた種別・フットプリント・ピン対応は残し、価格・在庫・区分だけ更新
- つながらないときはエラーを表示し、内蔵部品・CSV取込で作業を続けられる
- スマホのブラウザから直接つながらない（CORSで拒否される）場合は、Cloudflare Workers に中継を置いて「設定」でURLを指定（[docs/jlcsearch-relay.md](docs/jlcsearch-relay.md)）

- 検索: 名称・メーカー型番・LCSC品番・パッケージ・値・電気的仕様。値の表記ゆれを吸収（`0.1uF` = `100nF`、`10KΩ` = `10k`）。種別・JLCPCB区分・在庫ありで絞り込み
- 部品データはシンボルとフットプリントを別々に持ち、**ピン番号↔パッド番号の対応**を保持。対応の誤り（パッドが無い・存在しないパッド・1パッドに複数ピン）を検出
- 内蔵フットプリント: チップ部品（0402〜1206）、SOD-123/323、SMA、SOT-23/23-5/223、SOIC/TSSOP/DIP、ピンヘッダ、JST PH、SMD電解、タクトスイッチなど。寸法は IPC-7351 / KiCad の公称値に合わせているが、**第6段階で KiCad 公式データと照合するまで「寸法未照合」と表示**
- 内蔵部品のLCSC品番は、確認できたもの以外は「要確認」と表示。LCSCページで確認して「確認済み」にできる
- 回路図へは「回路図に配置」、既存の部品には属性の「ライブラリから選ぶ」で割り当て。使った部品データはプロジェクトにコピーされ、プロジェクト単体で完結
- **ネットリスト**（メニュー → ネットリスト）: 「部品番号-パッド番号」単位の接続を生成してプロジェクトに保存。部品番号の重複・フットプリント不明・ピン対応の誤り・ネット名の衝突はエラー、未接続ピン・LCSC品番未設定などは警告。回路図を変えると「古い」と表示。JSON・テキストで書き出し可

### 第3段階で直した不具合
- 自動保存の待ち時間（1.5秒）中にページを再読込・終了すると変更が失われていた → 閉じる瞬間に未保存分を localStorage に退避し、次回起動時に復元


## 第2段階: 回路図エディタ

| 操作 | スマホ（タッチ） | タブレット＋マウス/ペン |
|---|---|---|
| 部品の配置 | 「部品」→一覧で選んでキャンバスをタップ、または一覧からキャンバスへドラッグ | 同左（キー `P`） |
| 選択 | タップ。「複数選択」ONでタップごとに追加・解除 | クリック、Shift/Ctrl+クリックで追加 |
| 範囲選択 | 長押ししてからドラッグ | 空白をドラッグ |
| 移動 | 部品をドラッグ（グリッドに吸着、つながった配線は直角を保って追従） | 同左 |
| パン／ズーム | 空白を1本指ドラッグ／2本指ピンチ | 中ボタン・右ボタンドラッグ／ホイール |
| 回転・ミラー・削除 | 下部ツール、または上部のチップ | `R`・`M`・`Delete` |
| 配線 | 始点→次の点をタップ。ピン・配線・ラベルに着くと自動終了。曲げ方向は切替可 | 同左（キー `W`） |
| 配線の分岐 | 既存配線の途中から引き出す（分岐点で配線を分割し、接続ドットを表示） | 同左 |
| ネットラベル | 「ラベル」→配線やピンの上をタップして名前入力 | キー `L` |
| GND・電源記号 | 「電源」→ VCC / +5V / +3V3 / GND など | 同左 |
| 属性編集 | 長押し、または「属性」チップ | ダブルクリック、キー `E` |
| 元に戻す・やり直す | 上部の ↶ ↷ | `Ctrl+Z` / `Ctrl+Y` |

- 部品番号は種別ごとに自動採番（R1, C1, D1, Q1, U1, J1, SW1, BT1…）。メニューから位置順に振り直し可
- 初期対応部品: 抵抗、可変抵抗、コンデンサ、電解コンデンサ、インダクタ、ダイオード、LED、ツェナー、NPN/PNPトランジスタ、Nch/Pch MOSFET、オペアンプ、汎用IC（ピン数・ピン名を指定）、コネクタ（ピン数指定）、スイッチ、電池・電源、電源記号、GND
- 各ピンに番号・名前・電気的属性（入力/出力/双方向/電源入力/電源出力/パッシブ）を定義
- **接続の扱い**: 配線は電気的接続として計算する。端点が他の配線上・ピン上にあれば接続、線の途中同士の交差は非接続。3本以上集まる点にだけ接続ドット。同名のネットラベル・電源記号は離れていても同じネット
- 未接続のピン先端は赤い丸で表示。メニュー「接続一覧（確認用）」で計算結果を確認できる（製造用ネットリスト出力は第3段階）

### 既知の制約（第2段階時点）
- シートは1枚のみ（階層シートは未対応）
- コピー＆ペーストは未対応

## 第1段階: 保存まわり

- プロジェクトの新規作成・名前変更・複製・削除
- IndexedDBへの保存（自動保存: 操作が止まって1.5秒後、連続操作中でも10秒ごと、アプリ切替時は即時）
- 世代バックアップ（直近10回分）と、そこからの復元
- JSONでの書き出し・読み込み（同じIDなら「上書き」か「コピーとして追加」を選べる。壊れたファイルや新しいバージョンのファイルは読み込まずにエラー表示）
- オフライン起動（Service Worker）、ホーム画面への追加
- スマホ縦画面: 上=主要操作、中央=キャンバス、下=編集ツール／タブレット横画面: 左レール＋右パネル
- キャンバスのパン（1本指）とピンチズーム（2本指）。2本目の指が触れた時点で1本指の操作は破棄する

## 公開（GitHub Pages）

ビルドは不要です。リポジトリにこのフォルダの中身を置き、Settings → Pages で公開するブランチ（ルート）を選びます。
`.nojekyll` も同梱しています。

**更新時は `sw.js` の `CACHE` を書き換えてください**（キャッシュ優先なので、変えないと古い版が表示され続けます）。

## テスト

```bash
npm test                               # 単体テスト（60件: データモデル・自動保存・表示変換・接続計算・編集操作・履歴・フットプリント・部品・取込・ネットリスト）
python3 -m http.server 8765 &          # 別ターミナルでも可
node tests/e2e.mjs                     # 保存まわりの実ブラウザテスト（16件）
node tests/e2e-schematic.mjs           # 回路図エディタの実ブラウザテスト（24件、タッチ操作とマウス操作）
node tests/e2e-library.mjs             # 部品ライブラリ・取込・ネットリスト・オンライン検索の実ブラウザテスト（21件、通信はテスト内で差し替え）
```

E2EはPlaywrightを使います（`npm i -D playwright`。スクリプト冒頭の import パスと `executablePath` は環境に合わせて変更してください）。

## データ保存についての注意

データはその端末のブラウザ内に保存されます。Chromeのサイトデータを消すと消えるため、大事なプロジェクトはJSONで書き出してください（起動時に `navigator.storage.persist()` で自動削除されにくくするよう依頼しています）。
