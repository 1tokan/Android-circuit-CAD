# 回路シミュレーションの確認手順（0.13.0）

Android の実機（Pixel 9a など）で、回路シミュレーション（「シミュ」タブ）と、サンプルの基板（四隅の取付穴・検査の結果）を確かめる手順です。
計算は端末の中だけで行います（ネット接続は要りません）。

## 準備

1. APK（pocket-eda.apk）を入れ直し、アプリを起動する。右上のメニュー →「このアプリについて」で版が **0.13.0** であること
2. 左上のメニュー（プロジェクト一覧）→「サンプル」→「USB DAC アンプ」を開く（開くたびに新しいプロジェクトになるので、何度でもやり直せます）

## A. サンプルの基板（PCB タブ・検査タブ・出力タブ）

| # | 操作 | 確かめること |
|---|---|---|
| A1 | PCB タブを開く | 基板が **60.0 × 34.0 mm**。四隅に **M3 の穴（φ3.2）** と、その外側に**破線の円（ネジの頭の範囲 φ6）**。円の中に配線・ビア・ベタ・部品が無い |
| A2 | 検査タブ →「DRC実行」 | **エラー 0・警告 0**（情報だけ: 基板の端から出るコネクタ 4 件・取り除いたベタの島） |
| A3 | 検査タブ →「ERC実行」 | エラー 0・警告 0 |
| A4 | PCB タブで四隅の穴を 1 つタップ → 下の「属性」 | 直径 3.2・ネジの頭の範囲 6 |
| A5 | PCB タブ → 下の「外形」→ チップ「四隅に取付穴」→「置く」 | 「四隅には既に取付穴があります」と出る（二重に置かない） |
| A6 | 出力タブ → Gerber 書出 → JLCPCB のビューアで開く | 四隅に穴、穴の周りに銅が無い。表のシルク（USB-C・ジャック・スピーカー端子の外形線）が基板の端で切れている |
| A7 | 出力タブ →「KiCad」→ ZIP を PC の KiCad 7 で開き、PCB エディタの DRC | **違反 0・未接続 0**（PC で確かめる場合。tests/tools/kicad-verify.mjs と同じ結果） |

## B. 回路シミュレーション（シミュ タブ）

### B1. 画面

1. 上の作業領域のタブの右端「シミュ」をタップ（タブの右上の点は「一部実装」の印。メニューの「モジュール状況」に未実装の項目が出ます）
2. 下のツールに「実行」「信号源」「SPICE」の 3 つ。サンプルには信号源 2 つ（`VBUS_IN`: USB を挿した瞬間の 0→5V、`VDAC`: DAC の出力に AC 1V）と、過渡解析の設定（刻み 100u・終了 300m）が最初から入っています。**信号源を足さずにそのまま「実行」**できます
3. 注意: 電圧源は同じネットに 2 つつなげません（並列・ループは解けません）。足そうとすると止めて知らせ、計算の前にもループの部品の名前を挙げて知らせます

### B2. 過渡解析（USB を挿した瞬間の電源の立ち上がり）

1. 「信号源」の欄に `VBUS_IN 電圧源 VBUS → GND・DC 0・PULSE(0 5 1m 100u 1m 1 2)` があることを確かめる（タップすると中身が見られます）
2. 上で「過渡（時間波形）」が選ばれ、刻み `100u`・終了時刻 `300m` になっている
3. 「▶ 実行」（または下の「実行」）
4. 確かめること
   - 1 秒以内にグラフが出る。**電圧（V）と電流（A）は別の段**のグラフで、x 軸とカーソルは共通。`V(VBUS)`・`V(+5V_SYS)`・`V(SYS_G)`・`I(VBUS_IN)` が最初から表示されている（「表示する信号」の上の段に、線と同じ色の印つきで並ぶ）
   - `V(+5V_SYS)`（Q1 AO3401A の後ろ）が **約 100ms で 4.5V** に上がる（ngspice で同じ回路: 99.1ms）。`V(SYS_G)`（ゲート）がゆっくり下がる
   - `I(VBUS_IN)` の最大（の大きさ）がおよそ **−105mA**（電源から流れ出る向きが負）
   - 「測定」の表に最小・最大・P-P・平均・実効値が出る

### B3. カーソル・拡大・FFT・CSV

1. グラフに触れる → 黄色のカーソル A（上に「A」のつまみ）。別の所にもう一度 → 水色の B。表に A・B・B−A の値と時間差（とその逆数の周波数）
2. **A か B を指で左右にドラッグ** → カーソルが付いてきて、表の値も動く（両方あるときは指に近い方が動く。縦に動かすと画面がスクロールする）。電圧と電流の段で同じ位置に出る
3. 「A〜B を拡大」→ A〜B の範囲だけ表示。「全体」で戻る。「カーソルを消す」で消える
4. 「FFT」→ 周波数軸（対数）の dB 表示（電圧と電流は別の段）。もう一度「FFT」で戻る
5. 「CSV 書出」→ ファイルが保存される（表計算で開ける）
6. 「表示する信号」: 上の段の色つきボタンに触れると、その信号を外す。「電圧（ネット）」「電流（部品）」の組を開いて選ぶ。絞り込みに名前（例: `R5`）を入れると、合う組が開く

### B4. 動作点

1. 「動作点」→「実行」
2. 「ネットの電圧」と「部品」（Q1 の Vgs・Vds・Id・消費電力、抵抗の電流と消費電力など）の表が出る

### B5. AC 解析（周波数特性）

1. 「信号源」の欄に `VDAC 電圧源 DAC_OUTL → GND・DC 0・AC 1` があることを確かめる
2. 「AC（周波数特性）」を選ぶ（目盛り「10 倍ごと」・点の数 `20`・開始 `10`・終了 `10Meg` が入っている）→「実行」
3. 「表示する信号」で「すべて外す」→ 絞り込みに `LINE_L` → `LINE_L` を選ぶ
4. 確かめること: R5（470Ω）と C24（2.2nF）のローパスで、「−3dB の周波数」が **約 150kHz**（計算値 154kHz）。「dB＋位相」で位相も出る

### B6. 直流スイープ

1. 「直流スイープ」→ 信号源 `VBUS_IN`、開始 `0`、終了 `5`、刻み `0.05` →「実行」
2. VBUS が約 1V（Q1 のしきい値 0.9V）を越えると、`V(+5V_SYS)` が VBUS と同じ電圧になる（Q1 が入る）。それより下は Q1 が切れていて +5V_SYS は浮いている（つながる負荷が無いので VBUS の半分ほどの値になる）

### B7. 部品のモデル・チューニング

1. 「部品のモデル」を開く → Q1 が「AO3401A（−30V・Vth −0.9V…）」、U4 などの IC が「外す」（モデルなし）
2. R15 をタップ → モデルの画面が出る（キャンセルで閉じる）
3. 過渡解析に戻して実行 →「チューニング」で部品 `C39` を選び、つまみを動かして離す → すぐ計算し直され、立ち上がりの速さが変わる（C39 を大きくすると遅くなる）
4. 「この値を回路図に反映」は押さずに閉じてよい（押すと回路図の値が変わります。元に戻すで戻せます）

### B8. SPICE 書き出し

1. 下の「SPICE」→ `.cir` ファイルが保存される
2. （PC で確かめる場合）ngspice で `ngspice サンプル.cir` → 同じ解析が走る。KiCad の回路シミュレータと同じ ngspice なので、そちらでも比べられます

### B9. エラーの出方

1. 信号源を全部消して過渡解析を「実行」→ 止まらずに計算が終わり（電源が無いので全部 0V）、「注意」に「計算に入れない部品」が出る
2. 過渡で終了時刻を空にして実行 →「終了時刻「」を数として読めません」と出る
3. 「信号源」で電圧源を足し、＋を `VBUS`（`VBUS_IN` と同じ）にして保存 →「VBUS–GND には電圧源 VBUS_IN があります…」と出て保存されない（キャンセルで閉じる）

## C. 自動試験で確かめていること（参考）

- `npm test`: 値の読み書き、RC の時定数・遮断周波数、2N3904 の動作点（ngspice 42 と 1e-5 以内）、ダイオード・ツェナー、MOSFET のオン抵抗、オペアンプの利得・GBW・飽和、直流スイープ、SPICE の読み書き、測定と FFT、サンプルの電源の入口（ngspice: 4.5V まで 99.10ms・最大 104.7mA）。基板: 四隅の穴・ネジの頭の範囲の DRC とベタ、角丸パッドの距離、スポークの向き、シルクの切り取り、サンプルの DRC エラー・警告 0
- `node tests/tools/sim-ngspice.mjs`（ngspice が要る）: RC・半波整流・CE 増幅（AC・過渡）・P-MOS の立ち上げ・オペアンプ（飽和あり）・サンプルを ngspice と比べ、差は最大値の 0.11% 以内
- `node tests/tools/kicad-verify.mjs samples/usb-dac-amp.json /tmp/kv`（kicad-cli 7 が要る）: KiCad の DRC 違反 0・未接続 0、部品・配線・ビア・ベタ・パッドの位置が一致
- `npm run e2e`: tests/e2e-sim.mjs で B2〜B8 と同じ操作を実ブラウザ（スマホ表示）で行う

## まだできないこと（KiCad の回路シミュレータとの差）

雑音解析・極零解析・伝達関数・感度解析、B 素子（式で書く電源）・JFET・スイッチ素子（S・W）・伝送線路、.param・.lib・.include、BSIM などのレベル 2 以上の MOSFET モデル、温度を変えた計算。IC はメーカーの SPICE モデル（上の素子だけでできたもの）を「ライブラリ」に貼って割り当てたときだけ計算に入ります。
